Chat model -
------------
When you use  chat model , you can either just give the prompt or you can give multi user conversation
Ex: when invoking a model

llm = ChatOllama(model="gemma3:270m")
prompt = " Hi "
response1 = model.invoke("Hello")
response2 = model.invoke(prompt)
response3 = model.invoke(
    [
        ("system", "You are a helpful assistant."),
        ("human", "What is AI?"),
        ("ai", "AI is artificial intelligence."),
        ("human", "Give an example.")
    ]
)

response3 helps  the model to understand the conversation history.
The system message guides the model's behavior. Ex: ("system", "Explain like I'm 10 years old.") , ("system", "You are a Python tutor.")
[
    ("human", "My name is John"),
    ("ai", "Nice to meet you John"),
    ("human", "What's my name?")

Chain -
-------
A chain combines multiple components into a pipeline.
    chain = prompt_template | llm
    chain = retriever | prompt | llm

Instead of:
    prompt = f"Explain {topic}"
    response = llm.invoke(prompt)
you define:
    prompt = PromptTemplate(
        template="Explain {topic}",
        input_variables=["topic"]
    )
chain.invoke({
    "topic": "machine learning"
})

    ex: llm.bind_tools(tools=[tool1,tool2], tool_choice=["tool1"])
    this ensures that tool1 is used for sure

Pydant: -
-------
Pydantic is a Python library used for data validation, parsing, and type enforcement.
Think of it as a way to ensure that incoming data has the correct structure and types.

Without Pydantic
----------------
    user = {
        "name": "John",
        "age": "25"
    }
Here, age is a string. You have to manually check and convert it.

With Pydantic
--------------
from pydantic import BaseModel
class User(BaseModel):
    name: str
    age: int
user = User(name="John", age="25")
print(user)

Output:
name='John' age=25

Pydantic automatically converts "25" to 25.

Validation
from pydantic import BaseModel
class User(BaseModel):
    age: int
User(age="abc")

Output:
ValidationError:
age
  Input should be a valid integer

Why is it used in LangChain?
------------------------------
When creating tools, you can define exactly what inputs the tool accepts.

from pydantic import BaseModel, Field

class SearchInput(BaseModel):
    query: str = Field(description="Search query")

@tool(args_schema=SearchInput)
def search(query: str):
    return "results"

Benefits:

Input validation
Better tool descriptions
Helps the LLM understand the expected arguments
Prevents invalid tool calls
