ollama.chat() vs ChatOllama

This is a very important distinction. Think of it like driving a car directly vs. driving through an automatic driving assistant.

ollama.chat() → Directly talks to the Ollama server.
ChatOllama → A LangChain wrapper around ollama.chat() that makes it compatible with the LangChain ecosystem.

Rate Limiting
while embedding, multple documents are passed and the number of tokens passed has a limit.
The limit depends on the model being used.

For production grade applications rate limiting is needed.

retry_min_seconds
If any request fails then it will retry after some time.

----------------------------------------------------------------------------------------------------------------------------------------------
Chunk size is different for text splitter and embedding models
for text splitter : the text is splitter per chunk size
ex: a document of 1000 lines and chunk size is 100 then it is split into 10 chunks

for embeddings:
the chunk size here means How many chunks are embedded in one batch request.
ex: you got 10 chunks in the previous text splitter, now if you mention chunk size as 2 here,
then for every batch request sent 2 chunks will be sent

Why does Chroma work with asyncio.gather() but Pinecone doesn't?

The short answer is:
Chroma performs local database writes, whereas Pinecone performs network requests to a remote server.

Concurrent aadd_documents() on the same instance can fail for Pinecone
----------------------------------------------------------------------------------------------------------------------------------------------
Why "Recursive" Character Splitter?

Instead of blindly cutting at character 1000:

The capital of Fr | ance is Paris

it tries to split intelligently using:

Paragraphs (\n\n)
Lines (\n)
Spaces ( )
Characters

in that order.

2. TavilyMap
----------------
Crawl a website and discover pages/links.
Example website:

company.com
├── about
├── products
│   ├── laptop
│   └── keyboard
├── careers
└── contact

TavilyMap starts from:
company.com
and follows links.


max_depth=5
....................
Controls:

How many levels deep the crawler can go.

Example:

Level 0:
company.com

Level 1:
company.com/products

Level 2:
company.com/products/laptop

max_breadth=20
...................
Controls:

How many links per page can be followed.

Suppose homepage contains:
100 links

With:
max_breadth=20
the crawler only follows up to 20 links from that page.

max_pages=1000
...............
Controls:

Total number of pages allowed during the crawl.
